一、游戏规则
================================================================

1. 基本玩法
   - 校内线下追逐淘汰活动，为期 5 天。
   - 每人有一个“当前目标”，所有参与者构成一个全局单向环。
   - 淘汰目标后，猎人继承目标的目标，直到只剩 1 人。
   - 参与者按学院分为四个阵营：Red、Yellow、Blue、Green。
   - 每次有效击杀，击杀者阵营 +1 分（管理员可选择是否加分）。
   - 玩家击杀时需要输入目标本人的 6 位代码。
   - 管理员可在全局链中直接执行击杀，并选择是否给对应学院加分。

2. 事件生命周期
   draft（未开始）→ active（进行中）↔ paused（暂停）→ ended（已结束）
   - 开始活动：重置所有人状态为 alive，生成代码，随机生成环，学院分归零，状态改为 active。
   - 暂停：状态改为 paused，击杀被拒绝。
   - 继续：状态改为 active。
   - 结束：状态改为 ended，标记赢家。
   - 重新打乱：只对存活者重新生成环。
   - 重启游戏（再次点击“开始活动”）：删除所有击杀记录，清空每个人的“已击杀列表”，重置参与者状态，重新生成代码和环。

3. 击杀流程（玩家）
   1. 猎人点击击杀当前目标。
   2. 输入目标本人的代码。
   3. 服务端事务：
      - 校验事件为 active。
      - 锁定猎人和目标。
      - 校验猎人存活。
      - 校验目标存活且是猎人当前目标。
      - 校验输入代码等于目标本人的代码。
      - 标记目标淘汰。
      - 猎人继承目标的目标。
      - 猎人学院 +1 分。
      - 写击杀记录。
      - 胜利判定。
   4. 返回结果。

4. 击杀流程（管理员）
   - 管理员在“全局链”页面，对存活者点击“击杀+加分”或“击杀不加分”。
   - 服务端事务与玩家击杀类似，但不校验目标代码。
   - 击杀记录中 input_code = 'ADMIN'，points_awarded 为 1 或 0。
   - 写入审计日志。

5. 胜利判定
   - 只剩 1 人存活 → 该人获胜，事件结束。
   - 或猎人新目标是自己 → 猎人获胜，事件结束。
   - 获胜者 current_target_id 置为 null，status = 'winner'。
   - 事件 status = 'ended'，end_at = now()。

6. 撤销击杀
   - 只允许撤销最近一次有效击杀。
   - 恢复被淘汰者。
   - 恢复猎人目标。
   - 扣学院分（按 points_awarded 扣）。
   - 标记 status = 'revoked'。

7. 举报流程
   - 玩家提交 → 进 reports 表。
   - 管理员查看（可见举报人）。
   - 处理：resolved / rejected。
   - 不可删除。

8. 身份确认
   - 首次登录需确认身份。
   - 显示姓名、照片、学院。
   - “这是我” → confirm_identity() → 进入个人页。
   - “这不是我” → report_identity_issue() → 退出登录。

9. 每日规则
   - 管理员发布每日规则（Day 1-5）。
   - 公共主页显示今日规则。

10. 审计日志
    - 记录管理员关键操作：开始活动、管理员击杀等。
    - 管理员可查看、删除单条日志、清空所有日志。

三、表的内容和关系
================================================================

1. colleges（学院表，兼阵营）
   字段：
   - id uuid 主键
   - name text 学院名，唯一
   - color_hex text 颜色
   - score integer 学院分（=阵营分）
   - created_at timestamptz
   - updated_at timestamptz
   初始数据：Red、Yellow、Blue、Green

2. events（事件表）
   字段：
   - id uuid 主键
   - name text 事件名
   - status text draft / active / paused / ended
   - start_at timestamptz
   - end_at timestamptz
   - current_day integer 1-5
   - created_at timestamptz
   - updated_at timestamptz

3. participants（参与者表）
   字段：
   - id uuid 主键
   - event_id uuid → events.id
   - email text 学校邮箱，唯一
   - name text 姓名
   - photo_url text 照片
   - college_id uuid → colleges.id
   - code text 唯一代码（6位，排除 O0I1L）
   - status text alive / eliminated / winner
   - current_target_id uuid → participants.id
   - eliminated_by_id uuid → participants.id
   - eliminated_at timestamptz
   - is_confirmed boolean
   - confirmed_at timestamptz
   - created_at timestamptz
   - updated_at timestamptz
   约束：email 唯一、code 唯一、current_target_id <> id

4. eliminations（击杀记录表）
   字段：
   - id uuid 主键
   - event_id uuid → events.id
   - hunter_id uuid → participants.id
   - target_id uuid → participants.id
   - hunter_college_id uuid → colleges.id
   - target_college_id uuid → colleges.id
   - input_code text 输入的代码（管理员击杀为 'ADMIN'）
   - points_awarded integer 固定 1 或 0
   - status text valid / revoked
   - created_at timestamptz
   - revoked_at timestamptz
   - revoked_by uuid → admins.id
   - revoke_reason text

5. reports（举报表）
   字段：
   - id uuid 主键
   - event_id uuid → events.id
   - reporter_id uuid → participants.id
   - target_id uuid → participants.id
   - reason text
   - description text
   - evidence_url text
   - status text pending / resolved / rejected
   - admin_note text
   - handled_by uuid → admins.id
   - handled_at timestamptz
   - created_at timestamptz

6. daily_rules（每日规则表）
   字段：
   - id uuid 主键
   - event_id uuid → events.id
   - day_number integer 1-5
   - date date
   - title text
   - content text
   - published boolean
   - created_by uuid → admins.id
   - created_at timestamptz
   - updated_at timestamptz
   唯一约束：event_id + day_number

7. admins（管理员表）
   字段：
   - id uuid 主键
   - email text 管理员邮箱，唯一
   - name text 姓名
   - created_at timestamptz
   - updated_at timestamptz

8. audit_logs（审计日志表）
   字段：
   - id uuid 主键
   - event_id uuid → events.id ON DELETE SET NULL
   - admin_id uuid → admins.id ON DELETE SET NULL
   - admin_email text
   - action text NOT NULL
   - details jsonb DEFAULT '{}'::jsonb
   - created_at timestamptz DEFAULT now()
   索引：event_id、created_at DESC
   RLS：仅管理员可读、可删除

表关系：
- colleges 1:N participants
- events 1:N participants

- events 1:N reports
- events 1:N daily_rules

- participants 自关联：current_target_id、eliminated_by_id
- eliminations N:1 participants（hunter）
- eliminations N:1 participants（target）
- eliminations N:1 colleges（hunter_college、target_college）
- eliminations N:1 admins（revoked_by）
- reports N:1 participants（reporter、target）
- reports N:1 admins（handled_by）
- daily_rules N:1 admins（created_by）
- audit_logs N:1 admins（admin_id）

   - 可访问：全部页面
   - 可修改：所有数据
   - 可操作：导入、编辑、删除参与者、上传照片、设置学院、生成代码和环、开始/暂停/结束活动、发布规则、处理举报、撤销击杀、加减分、重置分、导出数据、全局链中击杀、查看/删除/清空审计日志

   - 发送登录邮件
   - 生成唯一代码
   - 生成随机环
   - 校验击杀代码
   - 事务更新环、状态、分数
   - 写审计日志

   - colleges：匿名可读，管理员可写
   - events：匿名可读，管理员可写
   - daily_rules：匿名只能读已发布，管理员可写
   - participants：玩家只能读自己，管理员全读全写
   - admins：仅管理员可读
   - eliminations：玩家只能读自己作为猎人的记录，管理员全读全写
   - reports：玩家可 insert，管理员可读可更新，不可删除
   - audit_logs：仅管理员可读、可删除

   - photos：匿名可读，管理员可写
   - evidence：玩家可上传，仅管理员可读

CREATE TABLE IF NOT EXISTS audit_logs (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  event_id uuid REFERENCES events(id) ON DELETE SET NULL,
  admin_id uuid REFERENCES admins(id) ON DELETE SET NULL,
  admin_email text,
  action text NOT NULL,
  details jsonb DEFAULT '{}'::jsonb,
  created_at timestamptz DEFAULT now()
);

CREATE INDEX IF NOT EXISTS idx_audit_logs_event_id ON audit_logs(event_id);
CREATE INDEX IF NOT EXISTS idx_audit_logs_created_at ON audit_logs(created_at DESC);

ALTER TABLE audit_logs ENABLE ROW LEVEL SECURITY;

DROP POLICY IF EXISTS "Admins can read audit logs" ON audit_logs;
CREATE POLICY "Admins can read audit logs" ON audit_logs
  FOR SELECT USING (is_admin());

DROP POLICY IF EXISTS "Admins can delete audit logs" ON audit_logs;
CREATE POLICY "Admins can delete audit logs" ON audit_logs
  FOR DELETE USING (is_admin());

2. admin_start_event（开始活动，含清空击杀记录、审计日志）
----------------------------------------------------------------
CREATE OR REPLACE FUNCTION public.admin_start_event()
RETURNS jsonb
LANGUAGE plpgsql
SECURITY DEFINER
AS $function$
DECLARE
  v_event_id uuid;
  v_count integer;
  v_ids uuid[];
  v_codes text[] := ARRAY[]::text[];
  v_code text;
  v_i integer;
  v_j integer;
  v_tmp uuid;
  v_alphabet text := 'ABCDEFGHJKMNPQRSTUVWXYZ23456789';
  v_code_len integer := 6;
  v_elim_count integer;
  v_attempts integer;
BEGIN
  IF NOT is_admin() THEN
    RETURN jsonb_build_object('error', 'not_admin');
  END IF;

  SELECT id INTO v_event_id
  FROM events
  ORDER BY created_at DESC
  LIMIT 1;

  IF v_event_id IS NULL THEN
    RETURN jsonb_build_object('error', 'no_event');
  END IF;

  SELECT count(*) INTO v_count
  FROM participants
  WHERE event_id = v_event_id;

  IF v_count < 2 THEN
    RETURN jsonb_build_object(
      'error', 'need_at_least_2_participants',
      'count', v_count
    );
  END IF;

  SELECT count(*) INTO v_elim_count
  FROM eliminations
  WHERE event_id = v_event_id;

  INSERT INTO audit_logs (event_id, admin_id, admin_email, action, details)
  VALUES (
    v_event_id,
    (SELECT id FROM admins WHERE email = current_user_email()),
    current_user_email(),
    'start_event',
    jsonb_build_object(
      'deleted_eliminations', v_elim_count,
      'participant_count', v_count,
      'timestamp', now()
    )
  );

  DELETE FROM eliminations WHERE event_id = v_event_id;

  UPDATE participants
  SET
    status = 'alive',
    eliminated_by_id = NULL,
    eliminated_at = NULL,
    current_target_id = NULL,
    code = NULL,
    updated_at = now()
  WHERE event_id = v_event_id;

  UPDATE colleges
  SET score = 0, updated_at = now()
  WHERE score <> 0;

  SELECT array_agg(id) INTO v_ids
  FROM participants
  WHERE event_id = v_event_id;

  FOR v_i IN 1..v_count LOOP
    v_attempts := 0;
    LOOP
      v_code := '';
      FOR v_j IN 1..v_code_len LOOP
        v_code := v_code || substr(
          v_alphabet,
          floor(random() * length(v_alphabet))::int + 1,
          1
        );
      END LOOP;
      v_attempts := v_attempts + 1;
      EXIT WHEN NOT (v_code = ANY(v_codes));
      IF v_attempts > 200 THEN
        RAISE EXCEPTION '无法生成唯一代码，请检查参与者数量或字母表';
      END IF;
    END LOOP;
    v_codes := array_append(v_codes, v_code);
    UPDATE participants
    SET code = v_code, updated_at = now()
    WHERE id = v_ids[v_i];
  END LOOP;

  FOR v_i IN REVERSE v_count..2 LOOP
    v_j := 1 + floor(random() * v_i)::int;
    v_tmp := v_ids[v_i];
    v_ids[v_i] := v_ids[v_j];
    v_ids[v_j] := v_tmp;
  END LOOP;

  FOR v_i IN 1..v_count LOOP
    UPDATE participants
    SET current_target_id = v_ids[(v_i % v_count) + 1],
        updated_at = now()
    WHERE id = v_ids[v_i];
  END LOOP;

  UPDATE events
  SET
    status = 'active',
    start_at = now(),
    end_at = NULL,
    current_day = 1,
    updated_at = now()
  WHERE id = v_event_id;

  RETURN jsonb_build_object('success', true, 'count', v_count);
END;
$function$;

3. admin_kill_target（管理员在全局链中击杀）
----------------------------------------------------------------
CREATE OR REPLACE FUNCTION public.admin_kill_target(
  p_hunter_id uuid,
  p_award_points boolean DEFAULT true
)
RETURNS jsonb
LANGUAGE plpgsql
SECURITY DEFINER
AS $function$
DECLARE
  v_event_id uuid;
  v_event_status text;
  v_hunter participants%ROWTYPE;
  v_target participants%ROWTYPE;
  v_alive_count integer;
  v_points integer := 0;
  v_winner_name text;
BEGIN
  IF NOT is_admin() THEN
    RETURN jsonb_build_object('error', 'not_admin');
  END IF;

  SELECT id, status INTO v_event_id, v_event_status
  FROM events
  ORDER BY created_at DESC
  LIMIT 1;

  IF v_event_id IS NULL THEN
    RETURN jsonb_build_object('error', 'no_event');
  END IF;

  IF v_event_status <> 'active' THEN
    RETURN jsonb_build_object('error', 'event_not_active');
  END IF;

  SELECT * INTO v_hunter
  FROM participants
  WHERE id = p_hunter_id
  FOR UPDATE;

  IF v_hunter.id IS NULL THEN
    RETURN jsonb_build_object('error', 'hunter_not_found');
  END IF;
  IF v_hunter.status <> 'alive' THEN
    RETURN jsonb_build_object('error', 'hunter_not_alive');
  END IF;
  IF v_hunter.current_target_id IS NULL THEN
    RETURN jsonb_build_object('error', 'hunter_no_target');
  END IF;

  SELECT * INTO v_target
  FROM participants
  WHERE id = v_hunter.current_target_id
  FOR UPDATE;

  IF v_target.id IS NULL THEN
    RETURN jsonb_build_object('error', 'target_not_found');
  END IF;
  IF v_target.status <> 'alive' THEN
    RETURN jsonb_build_object('error', 'target_already_eliminated');
  END IF;

  UPDATE participants
  SET status = 'eliminated',
      eliminated_by_id = v_hunter.id,
      eliminated_at = now(),
      updated_at = now()
  WHERE id = v_target.id;

  UPDATE participants
  SET current_target_id = v_target.current_target_id,
      updated_at = now()
  WHERE id = v_hunter.id;

  IF p_award_points THEN
    v_points := 1;
    UPDATE colleges
    SET score = score + 1, updated_at = now()
    WHERE id = v_hunter.college_id;
  END IF;

  INSERT INTO eliminations (
    event_id, hunter_id, target_id,
    hunter_college_id, target_college_id,
    input_code, points_awarded, status, created_at
  ) VALUES (
    v_event_id, v_hunter.id, v_target.id,
    v_hunter.college_id, v_target.college_id,
    'ADMIN', v_points, 'valid', now()
  );

  INSERT INTO audit_logs (event_id, admin_id, admin_email, action, details)
  VALUES (
    v_event_id,
    (SELECT id FROM admins WHERE email = current_user_email()),
    current_user_email(),
    'admin_kill',
    jsonb_build_object(
      'hunter_name', v_hunter.name,
      'target_name', v_target.name,
      'award_points', p_award_points,
      'timestamp', now()
    )
  );

  SELECT count(*) INTO v_alive_count
  FROM participants
  WHERE event_id = v_event_id AND status = 'alive';

  IF v_alive_count = 1 THEN
    UPDATE participants
    SET status = 'winner',
        current_target_id = NULL,
        updated_at = now()
    WHERE event_id = v_event_id AND status = 'alive';

    UPDATE events
    SET status = 'ended',
        end_at = now(),
        updated_at = now()
    WHERE id = v_event_id;

    SELECT name INTO v_winner_name
    FROM participants
    WHERE event_id = v_event_id AND status = 'winner'
    LIMIT 1;

    RETURN jsonb_build_object(
      'success', true,
      'winner', true,
      'winner_name', v_winner_name
    );
  END IF;

  RETURN jsonb_build_object('success', true, 'winner', false);
END;
$function$;

CREATE OR REPLACE FUNCTION public.admin_get_audit_logs()
RETURNS jsonb
LANGUAGE plpgsql
SECURITY DEFINER
AS $function$
DECLARE
  v_logs jsonb;
BEGIN
  IF NOT is_admin() THEN
    RETURN jsonb_build_object('error', 'not_admin');
  END IF;

  SELECT jsonb_agg(
    jsonb_build_object(
      'id', id,
      'event_id', event_id,
      'admin_email', admin_email,
      'action', action,
      'details', details,
      'created_at', created_at
    ) ORDER BY created_at DESC
  ) INTO v_logs
  FROM audit_logs;

  RETURN COALESCE(v_logs, '[]'::jsonb);
END;
$function$;

CREATE OR REPLACE FUNCTION public.admin_delete_audit_log(p_log_id uuid)
RETURNS jsonb
LANGUAGE plpgsql
SECURITY DEFINER
AS $function$
BEGIN
  IF NOT is_admin() THEN
    RETURN jsonb_build_object('error', 'not_admin');
  END IF;

  DELETE FROM audit_logs WHERE id = p_log_id;

  RETURN jsonb_build_object('success', true);
END;
$function$;

CREATE OR REPLACE FUNCTION public.admin_clear_audit_logs()
RETURNS jsonb
LANGUAGE plpgsql
SECURITY DEFINER
AS $function$
BEGIN
  IF NOT is_admin() THEN
    RETURN jsonb_build_object('error', 'not_admin');
  END IF;

  DELETE FROM audit_logs WHERE id IS NOT NULL;

  RETURN jsonb_build_object('success', true);
END;
$function$;
