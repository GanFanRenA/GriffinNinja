# NinjaTag 功能清单

最后更新：2026-10-12

本文档汇总当前版本已实现的全部功能。

---

## 一、账号系统

### 【1.1 注册】
- 页面：`register.html`
- 输入学校邮箱（`@bjsmicschool.com`），发送注册邮件（Magic Link）
- 邮件中的链接指向 `set-password.html`

### 【1.2 设置密码】
- 页面：`set-password.html`
- 从邮件链接进入后，Supabase 自动解析 token
- 输入新密码（≥ 6 位）+ 确认密码
- 保存后自动跳转到后台

### 【1.3 登录】
- 页面：`login.html`
- 输入邮箱（或姓名）+ 密码
- 支持"邮箱登录"和"姓名登录"两种方式
  （姓名登录需后端 RPC `resolve_login_email`）
- 非管理员登录会被强制登出并跳回首页

### 【1.4 退出】
- 所有已登录页面顶部/侧边栏有"退出"入口

## 二、公共主页（`index.html`）

### 【2.1 板块】
- 活动状态（未开始 / 进行中 / 已暂停 / 已结束）
- 当前天数（仅进行中显示）
- 阵营分数
- 存活 / 淘汰人数（赢家计入存活）
- 今日规则
- 存活墙（含赢家）
- 最终赢家（活动结束后显示）

### 【2.2 数据刷新】
- 每 5 秒轮询一次
- 页面隐藏时暂停轮询
- 存活墙做数据指纹，避免重复渲染

### 【2.3 可见性】
- 由后台"设置"控制每个板块对匿名访客是否可见
- 管理员登录后始终可见全部板块

---

## 三、管理后台（`admin.html`）

### 【3.1 布局】
- 桌面端：左侧固定侧边栏 + 右侧内容区
- 移动端：顶部标题 + 底部固定导航
- 侧边栏导航项：
  概览 / 参与者 / 学院 / 每日规则 / 全局链 / 记录 / 管理员 / 设置
- 移动端底部导航只保留 5 个高频项
- 顶栏右侧提供语言切换器
- 顶栏"查看首页"为同标签跳转（不打开新窗口）

### 【3.2 概览页】
- 状态英雄卡：显示活动状态、名称、存活/淘汰人数、当前天数
- 根据状态动态显示操作按钮：
  - 未开始：[开始活动] [重新打乱]
  - 进行中：[暂停活动] [重新打乱] [结束活动]
  - 已暂停：[继续活动] [重新打乱] [结束活动]
  - 已结束：[开始新活动] [查看记录]
- 下一步建议条（动态提示，如"今日规则未发布"）
- 阵营分数卡片
- 今日规则摘要
- 最近 5 条动态（击杀/撤销/复活）
- 事件配置（名称、当前天数）

### 【3.3 事件操作】
- 开始活动：重置所有参与者、生成新代码、生成击杀环、学院分归零
- 开始新活动：活动结束后同一入口，文案区分
- 重新打乱存活者：只对存活者重新生成环
- 暂停 / 继续
- 结束活动：需输入「结束活动」确认
- 修改事件名称与当前天数

### 【3.4 参与者管理】
- 添加单个参与者
  - 姓名（必填）
  - 年级（下拉：G9 / G10 / G11 / G12 / Teacher）
  - House / 学院（下拉）
  - 邮箱（学校邮箱校验 + 唯一性）
  - 照片（URL 输入）
- CSV 批量导入
  - 列顺序：`name, grade, house, photo_url, email`
  - 支持双引号包裹、引号内逗号、`""` 转义
  - 支持预览：表格展示解析结果，重复邮箱/非法年级标红
  - 自动跳过表头、空姓名行
- 编辑参与者（Modal）
  - 可修改姓名、年级、House、邮箱、照片
- 删除参与者（单条 + 批量）
  - 同步清理击杀记录、举报、相关引用
- 筛选
  - 关键字搜索（姓名/邮箱/代码/年级）
  - 学院筛选
  - 状态筛选（存活/已淘汰/赢家）
  - 年级筛选
- 批量操作
  - 表头全选 / 单行勾选
  - 批量分 House
  - 批量改年级
  - 批量删除

### 【3.5 学院管理】
- 列表展示：色点 + 名称 + 分数 + 人数
- 行内操作：编辑 / +1 / -1
- 编辑 Modal：名称 + 颜色选择器
- 重置所有学院分数（危险操作，需确认）

### 【3.6 每日规则】
- 发布 / 编辑
  - 天数（Day 1-5）
  - 标题
  - 内容
- 已发布列表按 Day 升序排列
- 点击编辑回填表单

### 【3.7 全局链】
- 两个可折叠卡片：
  - 重新加入已淘汰者
  - 全局链（主卡片）
- 折叠状态保存在 `localStorage`
- 全局链表：
  - Hunter / 代码 / 目标 / 目标代码 / 状态
  - 搜索（姓名/代码/目标名/目标代码/学院）
  - 状态筛选
  - 存活且有目标的行显示"完成击杀"按钮
  - 活动未进行时按钮禁用

### 【3.8 击杀流程】
- 点击"完成击杀" → Modal
- 5 种击杀原因：
  - 正常击杀（得分）
  - 违反规则（得分）
  - 未完成任务（得分）
  - 缺勤（得分）
  - 不计分击杀（不得分）
- 选择原因后实时显示"将给 XX 学院 +1 分"
- 确认后执行击杀：
  - 目标标记 eliminated
  - 猎人继承目标
  - 学院 +1（若计分）
  - 写 `eliminations` 记录
  - 判断胜利
- 剩 2 人击杀时：
  - 猎人 → winner
  - 事件 → ended
  - 显示"XX 获胜，活动已结束"

### 【3.9 重新加入已淘汰者】
- 搜索已淘汰者（防抖 250ms）
- 选择插入位置（存活且有目标的 Hunter）
- 语义：Hunter → 新加入者 → 原目标
- 效果：恢复 alive、清空淘汰信息、生成新代码、
  继承 Hunter 原目标、Hunter 目标指向新加入者

### 【3.10 记录】
- 击杀记录表：
  - 猎人 → 目标、原因、学院、时间、状态
  - 有效击杀可"撤销"
- 撤销击杀：
  - 恢复被淘汰者
  - 恢复猎人目标
  - 扣回学院分
  - 记录撤销原因
- 历史记录（合并三类）：
  - 击杀（valid eliminations）
  - 撤销（revoked eliminations）
  - 复活（audit_logs / reinsert 记录）
- 历史搜索：姓名 / 学院 / 原因 / 操作者 / 类型
- 按时间倒序，显示绝对时间 + 相对时间

### 【3.11 管理员管理】
- 查看管理员列表
- 添加管理员（邮箱 + 姓名）
- 移除管理员
  - 不能移除自己
  - 至少保留一名管理员
  - 二次确认

### 【3.12 设置页】
- 首页板块可见性
  - 平铺开关：活动状态 / 阵营分数 / 人数 / 今日规则 / 存活墙
  - 分组开关："最终赢家"作为父项，下挂 4 个附属奖项：
    - 个人赢家
    - 阵营赢家
    - 最多淘汰
    - 最快阵亡
  - 关闭父开关时子开关自动变灰禁用
  - 切换即保存

## 四、最终赢家（4 个奖项）

### 【4.1 显示条件】
- 只在活动结束时显示
- 总开关"最终赢家"关闭时整块隐藏
- 每个子奖项独立开关，可单独隐藏
- 管理员绕过所有开关，始终看到 4 个

### 【4.2 奖项数据】
- 个人赢家：`participants.status = 'winner'`
- 阵营赢家：`colleges.score` 最高的学院
- 最多淘汰：valid eliminations 中 hunter 击杀次数最多
- 最快阵亡：`eliminated_at` 最早的被淘汰者

### 【4.3 缓存】
- 按 `event.id` 缓存 `get_winner_stats` 结果
- 活动状态变化时清空缓存

## 六、权限与安全

### 【6.1 角色】
- 匿名访客：仅公共主页
- 管理员：全部后台功能

### 【6.2 RLS】
- 所有表启用行级安全
- 玩家侧入口已关闭（`me.html` / `confirm.html` 硬关闭）

### 【6.3 学校邮箱】
- 域名限制：`@bjsmicschool.com`
- 前端校验 + 后端 RPC `is_school_email` 双重检查

### 【6.4 唯一性约束】
- `participants.email` 唯一（null 除外）
- `participants.code` 唯一（6 位，排除 O0I1L）
- `participants.current_target_id <> id`

## 七、数据处理

### 【7.1 开始活动（严格模式）】
- 默认启用"避免同 House 互为目标"
- 贪心算法生成环顺序
- 若最大 House 人数 > 总人数一半，返回错误
- 前端弹窗提示，管理员可选：
  - 取消（不改动数据）
  - 忽略规则，用普通随机生成

### 【7.2 重新打乱存活者】
- 不启用同 House 规则（只对存活者随机）

### 【7.3 胜利判断】
- 击杀前存活人数 ≤ 2 → 猎人获胜
- 事件状态改为 `ended`

## 九、国际化（i18n）

### 【9.1 支持语言】
- 中文（`zh-CN`）— 默认
- 英文（`en`）

### 【9.2 语言选择与持久化】
- 初始化顺序：`localStorage` → 浏览器语言 → 默认中文
- `localStorage` 键：`ninjatag_locale`
- 切换语言同步更新 `<html lang>`
- 页面标题、静态文本、占位符、`title`、`aria-label` 均随语言切换

### 【9.3 语言包结构】
- 文件：`js/i18n.js`
- 命名空间：
  - `common`：通用按钮、状态、错误前缀
  - `auth`：登录 / 注册 / 设置密码
  - `public`：公共首页
  - `status`：状态枚举（draft/active/paused/ended/alive/eliminated/winner）
  - `killReason`：击杀原因
  - `admin`：后台全部文案

### 【9.4 静态文本替换】
- 属性驱动：
  - `data-i18n` → `textContent`
  - `data-i18n-html` → `innerHTML`
  - `data-i18n-placeholder` → `placeholder`
  - `data-i18n-title` → `title`
  - `data-i18n-aria-label` → `aria-label`

### 【9.5 动态文本替换】
- 所有 JS 模板字符串中的用户可见文本统一使用 `t(key)` 或 `t(key, params)`
- 带变量使用 `{name}` 占位符，例如 `t('admin.killSuccess', { target, pts })`
- 错误码映射改为：`错误码 → i18n key → 当前语言文案`
- 学院名、规则内容、活动名等数据库原文不做自动翻译

### 【9.6 切换响应】
- 语言切换触发 `onLocaleChange` 回调
- 各模块清空渲染签名缓存（`chainSignature`、`lastRenderedSignature`、`eliminationsSig`、`historySig`、`lastAliveWallKey`、`winnerStatsCache`）
- 当前页面 / 当前 Tab 自动重渲染

### 【9.7 入口位置】
- 公共页：顶部导航栏右侧
- 登录 / 注册 / 设置密码：顶部导航栏右侧
- 后台：顶栏右侧
